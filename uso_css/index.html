¿Qué son los selectores CSS?

Los selectores CSS permiten elegir elementos HTML para aplicarles colores, tamaños, márgenes y otros estilos.

Selector por clase

Se utiliza el punto para seleccionar una clase.

Selector combinado

Permite combinar diferentes criterios de selección.

Tipos de selectores

  • Selector universal
  • Selector de etiqueta
  • Selector descendente
  • Selector por clase
  • Selector por identificador
  • Selector hijo directo
  • Selector adyacente
  • Selector general de hermanos
  • Selector por atributo
